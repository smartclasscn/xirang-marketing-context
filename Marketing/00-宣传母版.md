## 1. 公司

长春息壤科技有限公司（简称息壤科技）成立于2026年5月8日，其前身为2024年6月组建的息壤工作室。经过近两年的技术积累与产品研发，公司完成企业化注册并开展市场化运营。

息壤科技是一家专注于数据库管理与数据应用的基础软件企业，以数据库技术为核心，围绕数据存储、管理、安全访问和应用支撑开展自主研发。

发展路径是技术、产品、生态、服务、价值——以技术为基础、以产品为载体、以生态为延伸、以服务为支撑、以价值为目标。

**技术。** G-Server（General Server Runtime，通用网络服务运行时）是息壤科技自主研发并独立维护的通用网络服务技术产品，以动态链接库形式提供可复用的网络服务能力，在 DBPrisma、QQDB、XRMeeting 中复用。领域语言是核心技术能力，体现在数据库查询语言 **XRQL** 中；不单列成通用产品，对外不称「领域语言产品」。

**产品。** 将技术能力转化为可交付的软件产品，包括 XRDB 系列、DBPrisma 与 XRMeeting 等。

**生态。** 建立围绕产品的技术适配、合作与产业协作关系（如 TheCa 等生态组件）。

**服务。** 为产品应用、部署和持续运行提供支撑。

**价值。** 通过技术与产品解决实际问题，形成客户价值与企业价值。

现有产品包括：

- **息壤数据库系列 XRDB**：嵌入式 **潇湘数据库 XXDB**、集中式 **青丘数据库 QQDB**。
- **息壤数据库串行审计安全网关 DBPrisma**。
- **息壤会议系统 XRMeeting**。

TheCa 是 XRDB 的图形化管理软件，基于 XXDB，属于 XRDB 生态，不单独销售。

## 2. 当前战略主线

- **信创方向**：信创是息壤科技的市场重点。产品自主可控，已完成信创适配与认证成果。在信创方向坚持差异化策略，重点面向 **AI 原生防线**、**生产数据库信创**、**渐进式解决方案**。
- **AI 原生方向**：以 AI4DB、DB4AI 为产业背景，结合多模、多数据结构与异构计算，优先探索 **AI4Science** 与 **AI4Engineering**。尚未完成验证的能力不写成已交付产品。
- **多数据结构生产数据库信创**：关系型为主且异构可通过关系模型解决的场景，与在关系库基础上对 KV、树、链表等结构依赖高、对性能质量要求高的场景相区分；**XRDB** 主要针对后者（如 BOM、全面预算等），通过物化数据结构提升效率与质量。
- **渐进式解决方案**：利用 **DBPrisma** 在不改写现有业务的前提下先完成访问控制、审计与兼容；结合多路广播等迁移能力，在保障生产安全的前提下渐进实现信创目标。须先 PoC，再作为并行运行与渐进替代路径。
- **嵌入式方向**：**XXDB** 面向端侧、边缘与嵌入式信创需求；先 PoC，不使用未经核实的市场规模数字。

## 4. DBPrisma

DBPrisma（息壤数据库串行审计安全网关）部署在现有数据库前面。企业无需修改任何一行原有业务应用的代码，只需将数据库连接地址指向 DBPrisma，即可平滑完成网关接入。在此前提下提供 SQL 防火墙、访问控制、行为审计和数据路由。国密、库版本、SHA-256 哈希链、四维合规报告和 Prometheus 监控的可用句子以 `00-对外口径.md` 的 DBPrisma 节为准。

互认证与适配范围以 `00-对外口径.md` DBPrisma 节为准：四个数据库（人大金仓、TIDB、GreatSQL、南大通用），三个操作系统（麒麟服务器操作系统、麒麟桌面操作系统、欧拉操作系统），一个信创硬件（鲲鹏）。不写证面版本号。软件著作权审批状态不写入对外正文。

对外点名互认证对象时，Great DB 与证面 **GreatSQL** 互认证书对应；贴徽标或引用证书时使用该张证书上的软件名，不把处理器写成操作系统。

## 5. XXDB 潇湘

XXDB（潇湘）是嵌入式数据库：以库或组件的形式集成到宿主应用程序中，通常与应用程序运行在同一进程内，由应用程序直接调用 XXDB 接口完成数据管理。

存储引擎为 pago，接口为 unia for pago。适合需要把数据库带进应用、设备和边缘节点的场景。

## 6. QQDB 青丘

QQDB（青丘）是集中式数据库：数据及其核心管理功能集中于一个逻辑数据库系统，由统一的数据库管理系统负责数据存储、查询处理、事务管理、并发控制和访问服务。

可以挂载 pago、aegis 存储引擎，或两个引擎同时挂载。

pago 存储引擎支持多种数据模型；多种数据结构在底层多以堆表形式物化，用于传统业务和对数据结构要求不高的环境。

aegis 版通过数据空间原生物化多种数据结构，用于数据结构要求较高的科研和工程环境。

合作与 PoC 文稿不写 CUDA 零拷贝。

## 7. XRDB 共性

以下能力属于 XRDB，同时适用于 XXDB 和 QQDB。

XRQL 覆盖关系、KV、文档、图数据模式，同时支持物化的树、链表、多维数组。

AI 可以插入 SQL 解析、优化、运维、存储四个层次。其中，自然语言转 SQL 在 AI4DB 侧已完成技术实现（其余 AI 插入能力按产品与版本为准）。

## 8. 智能体数据存储

智能体数据存储的表述同时适用于 XXDB 和 QQDB。

## 9. 数据库生态

TheCa 是 XRDB 的图形化管理软件，基于 XXDB，带图形界面。它是 XRDB 的生态组件，不单独销售，不单独报价。

语言驱动：提供 ODBC，以及 Java、C#、Python SDK。

## 10. 合作

息壤当前提供三类合作：

- 现有数据库的接入、访问控制、行为审计和数据路由（含信创渐进式路径讨论）。
- 嵌入式数据库在端侧、边缘和行业应用中的 PoC。
- 面向科学计算与工程数据的多数据结构和 XRQL PoC。
