# DBPrisma Enterprise 功能清单
**日期：** 2026年11月

DBPrisma Enterprise（息壤数据库串行审计安全网关）部署在现有数据库前面。清单按接入、路由与高可用、五层防护、审计、运维排列。表中「有」表示本产品具备该项。

企业无需修改任何一行原有业务应用的代码，只需将数据库连接地址指向 DBPrisma，即可平滑完成网关接入。平台可完全接管客户端身份校验，实现应用层账号与数据库底层账号的物理隔离。在此前提下提供 SQL 防火墙、访问控制、行为审计和数据路由。接入支持透明透传与认证托管，并提供连接池与多路复用。

当前支持 MySQL 和 PostgreSQL，以及兼容这两类数据库的信创产品。

## 接入

认证托管由网关接管身份校验。透明透传让业务连接穿过网关到达数据库。两条路径都把数据库连接地址指向 DBPrisma。

## 路由与高可用

数据路由提供读写分离，并把写操作按多后端写广播分发。熔断把异常后端分开；主后端不健康时，新连接可以转到健康后端。

## 五层防护

### IP 访问控制（ip_allowlist / ip_denylist）

来源地址先经过 IP 访问控制，由允许名单与拒绝名单决定连接是否可以建立。

### TLS 加密（客户端到网关，tls_termination）

客户端到网关的链路按 tls_termination 做 TLS 终结。支持基于铜锁（Tongsuo）密码库实现 TLCP 国密传输协议（GB/T 38636）以及 RFC 8998 国密 TLS 1.3，采用 SM2/SM3/SM4 国密算法，实现数据库链路国密加密。国际算法 TLS 与国密可以分段配置在客户端到网关、网关到数据库两侧。

### 认证与限速（代理用户与认证失败封禁）

认证阶段由代理用户承接身份校验，并对认证失败实施封禁。

### 连接配额（单 IP 连接数）

连接配额按单 IP 连接数控制入口占用。

### SQL 防火墙（预编译语句双阶段解析，黑白名单）

SQL 防火墙对预编译语句做双阶段解析，并按黑白名单拦截。命中黑名单的语句被拦截，白名单内的语句按规则放行。

## 审计

行为审计记录源 IP、身份、时间、SQL 和结果，并覆盖慢查询。审计日志可在落盘前对 SQL 字面量做脱敏。审计记录交给客户现有的安全信息与事件管理（SIEM），也可进入客户现有的安全运营中心（SOC）。导出格式为 json（NDJSON）、cef、syslog。审计导出可使用 SHA-256 哈希链锁定记录，每行带 prev_hash 与 line_hash。四维合规报告覆盖运维效率、安全威胁、性能基准、合规审计。

## 运维

部分配置可热重载；监听、安全策略、重组上限等须重启后生效。配置变更配有预检与回滚。管理接口同时提供 HTTP 与 HTTPS，只读；Prometheus 抓取 GET /metrics。

## 适配

互认证与适配范围为四个数据库（人大金仓、TIDB、GreatSQL、南大通用），三个操作系统（麒麟服务器操作系统、麒麟桌面操作系统、欧拉操作系统），一个信创硬件（鲲鹏）。
