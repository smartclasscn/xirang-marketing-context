## 4. 和现行对外短文的冲突（选稿前要先定）

1. 现行对外是单一产品名 DBPrisma。这套目录把能力拆成 Enterprise / Standard / DevOps / Education，并写 Standard 到 Enterprise 可在线授权升级。V1.0 写 Standard「无审计、无安全防护」，Standard 白皮书正文却包含 SQL 防火墙和审计句。两套不能同时对外。
2. 6 月总白皮书不分版本；7 月 Enterprise PDF 用「串联安全网关」和程度词。现行全称是「串行审计安全网关」。
3. 全栈稿写等保 2.0、数据安全法、麒麟、统信、飞腾、鲲鹏，并点名国产数据库。现行对外认证规则是不写型号、比较稿不写其他产品名。
4. 竞品报告中的哈希链、四维报告、1GiB 大包、虚拟补丁、表级 ACL，短文里没有。问答卡把其中若干条标成 2026-07 修订，仍是内部。
5. 热重载：市场稿写绝大部分配置热重载；Enterprise `03` 与 user 手册写 `security.*` 必须重启。
6. 教育 `1.1` 规格是给研发的 B/S+C/S 改造说明（C# 封装现有 C/C++ 引擎，学生浏览器操作 MySQL、PostgreSQL、达梦）。这是方案，不是已交付产品说明。`0` 号文件含七月推广和年底营收，不能进产品事实。
