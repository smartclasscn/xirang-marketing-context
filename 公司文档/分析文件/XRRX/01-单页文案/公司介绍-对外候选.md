长春息壤科技有限公司（息壤科技）成立于2026年5月8日，其前身为2024年6月组建的息壤工作室。经过近两年的技术积累与产品研发，公司完成企业化注册并开展市场化运营。息壤科技是一家专注于数据库管理与数据应用的基础软件企业，以数据库技术为核心，围绕数据存储、管理、安全访问和应用支撑开展自主研发，致力于为数字化业务和智能化应用提供数据基础设施。

息壤取意「生生不息、承载涵养」，寓意承载、滋养和持续生长；数据如同数字生态赖以生长的土壤，息壤科技专注数据管理与应用，为数据的安全存续、稳定流转和高效管理提供底层技术支撑。息壤科技以数据库内核研发和数据管理技术为核心，围绕数据库服务运行、数据访问、安全审计及业务应用支撑，构建自主研发的软件技术体系。公司坚持以技术为基础、以产品为载体、以生态为延伸、以服务为支撑、以价值为目标的发展路径，推动技术积累向产品能力转化，产品能力向产业应用延伸。

信创是息壤科技的市场重点。公司产品自主可控，完成信创产品适配与认证成果。在信创方向，息壤科技坚持差异化市场策略，重点面向 AI 原生防线、生产数据库信创和渐进式解决方案。嵌入式方向上，潇湘数据库 XXDB 面向端侧、边缘和嵌入式应用的信创需求。

息壤科技的主要软件研发语言包括 C/C++ 和 C#。现有产品包括息壤数据库系列 XRDB、息壤数据库串行审计安全网关 DBPrisma 和息壤会议系统 XRMeeting。XRDB 是息壤科技自主研发的数据库产品系列，当前包含嵌入式潇湘数据库 XXDB 与集中式青丘数据库 QQDB。G-Server（General Server Runtime，通用网络服务运行时）是息壤科技自主研发并独立维护的通用网络服务技术产品，以动态链接库形式提供可复用的网络服务能力，在 DBPrisma、QQDB 与 XRMeeting 中复用。领域语言设计与开发是息壤科技的核心技术能力之一，相关能力体现在息壤数据库查询语言 XRQL 的设计与实现中。息壤会议系统 XRMeeting 的网络服务运行能力复用 G-Server。

潇湘数据库 XXDB 是嵌入式数据库，以库或组件的形式集成到宿主应用程序中，通常与应用程序运行在同一进程内，由应用程序直接调用 XXDB 接口完成数据管理。

青丘数据库 QQDB 是集中式数据库。QQDB 的数据及其核心管理功能集中于一个逻辑数据库系统，由统一的数据库管理系统负责数据存储、查询处理、事务管理、并发控制和访问服务。QQDB 可以挂载 pago、aegis 存储引擎，或两个引擎同时挂载。pago 存储引擎支持多种数据模型，多种数据结构在底层多以堆表形式物化，用于传统业务和对数据结构要求不高的环境。aegis 版通过数据空间原生物化多种数据结构，用于数据结构要求较高的科研和工程环境。

信创数据库按数据结构需求可分为两类。第一类以关系型数据库为主，异构模型和数据类型可通过关系模型解决，且对性能和质量影响不高。第二类在关系模式数据库基础上，对异构模型和数据类型依赖高，且对性能和质量要求高。XRDB 主要面向第二类需求，例如 BOM、全面预算等场景；这些场景对 KV、树、链表等数据结构要求高，通过对物化数据结构的使用可提升效率和质量。

XRQL（息壤数据库查询语言）是 XRDB 产品系列使用的数据库查询语言。XRQL 在设计上面向关系、KV、文档、图及层次模型等数据模型；各数据模型上的具体语句与操作范围以产品实现和版本为准。层次模型与树、链表、多维数组等数据结构属于不同概念层次。XRQL 支持对树、链表和多维数组等数据结构进行相应操作，具体支持范围以产品实现和版本为准。智能体数据存储同时适用于 XXDB 和 QQDB。语言驱动提供 ODBC，以及 Java、C#、Python SDK。

TheCa 是 XRDB 的图形化管理软件，基于 XXDB，带图形界面，属于生态组件，不单独销售，不单独报价。

DBPrisma（息壤数据库串行审计安全网关）部署在现有数据库前面，业务系统不用改写，即可做 SQL 防火墙、访问控制、行为审计和数据路由（以当前版本为准）。在渐进式解决方案中，利用 DBPrisma 在不改写现有业务系统的前提下先完成访问控制、审计和兼容；多路广播等迁移能力须先 PoC 验证，再作为数据库并行运行、验证和渐进替代路径，在保证生产安全的基础上实现信创目标。

在 AI 原生方向，息壤科技以 AI4DB、DB4AI 为产业背景，结合多模、多数据结构和异构计算能力，优先探索 AI4Science 与 AI4Engineering。AI4DB 将人工智能技术应用于数据库的设计、管理、执行与优化过程，提高数据库性能、自动化水平及自治能力。XRDB 内核原生具有强契约 AI 插件管理，可将 AI 插入 SQL 解析、执行优化、运维和存储四个层次；上述 AI 插入同时适用于 XXDB 和 QQDB。自然语言转 SQL 已经完成技术实现。XRDB 支持异构算力执行优化，根据数据情况选择 CPU 或 GPU 算力。
