长春息壤科技有限公司（息壤科技）成立于2026年5月8日，其前身为2024年6月组建的息壤工作室。团队经过近两年的技术积累与产品研发，完成企业化注册并开展市场化运营。息壤科技是一家专注于数据库管理与数据应用的基础软件企业，以数据库技术为核心，围绕数据存储、管理、安全访问和应用支撑开展自主研发。

息壤科技的主要软件研发语言包括 C/C++ 和 C#。公司具备数据库服务端内核研发、数据库协议处理与通用网络服务运行时研发能力。领域语言设计与开发是息壤科技的核心技术能力之一，相关能力体现在息壤数据库查询语言 XRQL 的设计与实现中。该能力不作为独立产品，也不等同于通用 DSL。

G-Server（General Server Runtime，通用网络服务运行时）是息壤科技自主研发并独立维护的通用网络服务技术产品，以动态链接库形式提供可复用的网络服务能力，为不同应用提供网络连接管理、异步 I/O 处理和服务运行支撑。G-Server 在 Windows 平台采用 IOCP 异步 I/O 模型，在 Linux 平台采用 epoll 事件驱动模型。G-Server 已在 DBPrisma、QQDB、XRMeeting 中复用。

XRDB 是息壤科技自主研发的数据库产品系列，当前包含嵌入式数据库 XXDB（潇湘）与集中式数据库 QQDB（青丘）。

XXDB（潇湘数据库）是嵌入式数据库，以库或组件形式集成到宿主应用程序中，通常与应用程序运行在同一进程内，由应用程序直接调用 XXDB 接口完成数据管理。

QQDB（青丘数据库）是集中式数据库，数据及其核心管理功能集中于一个逻辑数据库系统，由统一的数据库管理系统负责数据存储、查询处理、事务管理、并发控制和访问服务。pago 与 aegis 是存储引擎，不是产品名。QQDB 可以挂载 pago、aegis 存储引擎，或两个引擎同时挂载。pago 存储引擎支持多种数据模型，多种数据结构在底层多以堆表形式物化，用于传统业务和对数据结构要求不高的环境。aegis 存储引擎通过数据空间原生物化多种数据结构，用于数据结构要求较高的科研和工程环境。

XRQL（息壤数据库查询语言）是 XRDB 产品系列使用的数据库查询语言。XRQL 在设计上面向关系、KV、文档、图及层次模型等数据模型；各数据模型上的具体语句与操作范围以产品实现和版本为准。层次模型与树、链表、多维数组等数据结构属于不同概念层次。XRQL 支持对树、链表和多维数组等数据结构进行相应操作，具体支持范围以产品实现和版本为准。以上 XRQL 表述同时适用于 XXDB 和 QQDB。语言驱动提供 ODBC，以及 Java、C#、Python SDK。

TheCa 是 XRDB 的图形化管理软件，基于 XXDB，带图形界面，属于生态组件，不单独销售，不单独报价。

DBPrisma（息壤数据库串行审计安全网关）是部署在现有数据库前的数据库安全网关产品，可在业务系统不用改写的前提下，提供 SQL 防火墙、访问控制、行为审计和数据路由（以当前版本为准）。已完成与人大金仓、TIDB、Great DB、南大通用的互认证。

XRMeeting（息壤会议系统）是息壤科技的会议系统产品。XRMeeting 的网络服务运行能力复用 G-Server。

AI4DB 将人工智能技术应用于数据库的设计、管理、执行与优化过程，提高数据库性能、自动化水平及自治能力。XRDB 内核原生具有强契约 AI 插件管理。把 AI 插入 SQL 解析、执行优化、运维和存储四个层次，是 XRDB 的技术方向，同时适用于 XXDB 和 QQDB。自然语言转 SQL 已经完成技术实现。XRDB 支持异构算力执行优化，根据数据情况选择 CPU 或 GPU 算力。
